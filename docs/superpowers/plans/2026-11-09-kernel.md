# Delta Core Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox syntax for tracking.

**Goal:** Deliver an executable Rust collaboration kernel and replaceable browser layer with a standalone typed TS integration.

**Architecture:** Pure domain and wire contracts sit inward of persistence, PTY and Pi adapters. The host authenticates members and records sequenced public events before broadcasting; personal drafts never enter the public protocol. TypeScript consumes generated protocol types through a small SDK.

**Tech Stack:** Rust 2024, serde, schemars, tokio, axum, SQLite, portable-pty; TypeScript, Vite, xterm, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-09-kernel-design.md`

## Global Constraints

- Preserve `vision.md` unmodified.
- Rust kernel and execution adapters; replaceable browser layer and independent TS SDK.
- Fixed execution host; explicit publication for text; immediate public execution activity.
- No model inference, microphone/audio, GUI activation, remote Git operations or external deployment during development.
- No silent revision overwrite, automatic execution replay, public bearer-token URLs, or arbitrary unauthenticated endpoints.

## Review Focus

- A reconnect occurring during output must not lose or duplicate events.
- A stale publication or rejected execution must retain the user's draft and not run a process.
- Non-owner members must not mint credentials or control another person's terminal.
- Pi acceptance and `agent_end` must not be confused with settled completion; finalized results supersede partial snapshots.
- Host restarts and child exits must not leave the page displaying a running session forever.

## Execution evidence

The initial read-only review covered `d910c50..996d852`. Its four findings were reproduced before fixes: PTY input backpressure blocked the control path; conflict approval used an unseen mutable revision; a backend could close its event channel without recording completion; and same-session followup prompts were not shared/durable. The fix pass added bounded per-terminal input workers, captured conflict revisions, atomic EOF cleanup with durable status, and journaled followup activity rendered by the layer. All targeted regressions failed first and passed after their fixes; no findings remain open.

Final checks: 22 Rust tests, 3 SDK tests and 7 headless browser tests pass; formatting, clippy with warnings denied, TS typecheck, deterministic schema generation and production browser build pass. `npm start` and the independent `npm run example` were exercised against a real temporary loopback host, then stopped. A real installed Pi RPC `get_state` handshake passed with zero prompts; actual model inference remains unverified, and replies to Pi extension dialogs are not implemented. Pi result/UI acceptance uses explicitly labeled protocol fixtures. Rich Markdown/Mermaid editing, sandboxing, multi-tenant deployment and distributed execution remain outside this initial slice.
